# Design system

Brand spelling is exactly **PRESSWRK.** Red period retained. Wordmark uses Arial Black, Helvetica Neue, Arial, sans-serif, weight 950, 30px desktop / 26px mobile, -1.8px tracking. No remotely fetched font.

Palette: paper `#faf9f6`, ink `#171719`, red `#cf2c39`, muted `#696866`, borders `#d9d6d0`, preview ground `#f4f2ed`, safe guides `#39776b`, error `#ad1426`.

Typography: Arial/Helvetica body, monospace labels/status. Large uppercase headline; body 14px, helper text 12px. Spacing: 4vw outer gutters, 23px panels, 13px paired inputs, 28px instructional gaps.

Three panels at wide desktop, two plus full-width preview below 1100px, one column below 600px. Minimum-width constraints must not create a horizontal scroll at 320px. Controls at least 44px high. Focus outlines visible, labels explicitly associated, errors live-announced; selected presets use aria-pressed. Preview includes an accessible geometry description. Do not rely only on guide colors for meaning.

No Figma reference. Original builder is the visual starting point. Screenshots in documentation/assets capture the implemented UI.
