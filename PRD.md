# Product requirements

## Problem and audience
Designers and print operators repeatedly rebuild packaging scaffolds or cannot find prior tools. Give them one public, stable link for preset/custom geometry and editable Illustrator output.

## User stories
- Choose a familiar container, edit measured dimensions and inspect cut/bleed/safe/seam geometry.
- Download a script that creates editable, named Illustrator layers and spot swatches.
- Send the exact setup to a collaborator without an account.
- Return to the last valid setup on the same browser and provide public feedback.

## Success criteria
Release gates: five presets and 1.25/2 inch circular customs validate; invalid geometry blocks export; sharing round-trips; desktop and 320px layouts remain usable; public URL, offline download and social image return 200.
Post-launch learning targets (not claimed outcomes): collect five actual job trials, identify the top three frictions, and confirm one successful Illustrator-to-fit workflow. No analytics installed; collect voluntary issue reports.

## Limits
Decimal inches, circles, rectangles and straight wraps. Illustrator required for `.ait`; no medical/regulatory certification, official symbol art, auto-white plate, tapered dielines or physical-fit guarantee.
