01 — Set your dimensions

For a 1.25″ or 2″ jar top, choose Custom → Concentrate jar lid and change the diameter. The height stays linked. Presets remain editable too.

02 — Run in Illustrator

Download the .jsx script. In Illustrator, choose File → Scripts → Other Script… and select it. Choose a destination folder; the script creates and saves a layered .ait template. Adobe Illustrator is required for this step.

03 — Add artwork & verify

CMYK, 300 ppi, ten layers and five spot swatches. Add approved artwork on the named layers, inspect separations, and test fit. Guides and gauge references do not print.
